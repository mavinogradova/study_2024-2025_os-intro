## Разбиение IPv6-сети на подсети

### Задание 1. Сеть 2001:db8:c0de::/48

Задана сеть 2001:db8:c0de::/48. Охарактеризуем адрес, определим маску, префикс, диапазон адресов для узлов сети (краевые значения). Разобьём сеть на 2 подсети двумя способами — с использованием идентификатора подсети и с использованием идентификатора интерфейса.

Тип адреса определяется по старшим битам в соответствии с табл. 3.5. Адрес 2001:db8:c0de::/48 начинается с 2001, что соответствует префиксу 2000::/3 — Global Unicast. При этом первые 32 бита (2001:DB8) соответствуют префиксу 2001:DB8::/32, который зарезервирован для документации и примеров.

Префикс /48, маска FFFF:FFFF:FFFF:0000:0000:0000:0000:0000 (3 полных блока по 16 бит). Краевые значения: первый адрес узла 2001:db8:c0de:0:0:0:0:1 (сокращённо 2001:db8:c0de::1), последний адрес узла 2001:db8:c0de:ffff:ffff:ffff:ffff:ffff. Диапазон: 2001:db8:c0de::1 – 2001:db8:c0de:ffff:ffff:ffff:ffff:ffff.

**Способ 1 — с использованием идентификатора подсети.** Меняем шестнадцатеричное число (идентификатор подсети), следующее за префиксом глобальной маршрутизации (48 бит). Исходный адрес имеет 4-й блок равным 0000. Меняя его на 0001 и 0002, получаем две подсети: 2001:db8:c0de:0001::/64 и 2001:db8:c0de:0002::/64. Префикс подсети становится /64. Этот способ удобен для явного выделения логических подсетей внутри одной сети.

**Способ 2 — с использованием идентификатора интерфейса.** Забираем 4 бита у идентификатора интерфейса, расширяя префикс с /64 до /68 (граница полубайта). В 5-м блоке меняем первую шестнадцатеричную цифру: 0 и 1. Получаем подсети 2001:db8:c0de:0000:0000::/68 и 2001:db8:c0de:0000:1000::/68. Идентификатор интерфейса уменьшается с 64 до 60 бит. Этот способ позволяет создавать подсети внутри уже существующей /64-сети.

Результат представлен на рис. [-@fig:009].

![Характеристики сети 2001:db8:c0de::/48 и разбиение на 2 подсети двумя способами](/home/mavinogradova/skreens/SetyLb3/9.png){#fig:009 width=70%}

**Как выполнялось задание.** Сначала охарактеризован адрес: по старшим битам (2001) определено соответствие префиксу 2000::/3 — Global Unicast; по первым 32 битам (2001:DB8) — соответствие зарезервированному префиксу для документации. Определены префикс /48, маска FFFF:FFFF:FFFF:0000:0000:0000:0000:0000 (3 полных блока), краевые значения диапазона (первый адрес — сеть + 1, последний — сеть + все F). Затем выполнено разбиение двумя способами: способ 1 — изменение идентификатора подсети (4-й блок), способ 2 — расширение префикса с /64 до /68 за счёт 4 бит идентификатора интерфейса (5-й блок).

Тип адреса определяется по старшим битам в соответствии с табл. 3.5. Адрес 2a02:6b8::/64 начинается с 2a02, первые три бита которого равны 001, что соответствует префиксу 2000::/3 — Global Unicast.
