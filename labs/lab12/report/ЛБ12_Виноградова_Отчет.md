# Цель работы

Изучить основы программирования в оболочке ОС UNIX/Linux. Научиться писать небольшие командные файлы.

# Выполнение лабораторной работы

1. Написать скрипт, который при запуске будет делать резервную копию самого себя (то есть файла, в котором содержится его исходный код) в другую директорию backup в вашем домашнем каталоге. При этом файл должен архивироваться одним из архиваторов на выбор zip, bzip2 или tar. Способ использования команд архивации необходимо узнать, изучив справку.(рис. [-@fig:001]).

![Пишем скрипт](/home/mavinogradova/skreens/skreens 12/скрины 12/1.png){#fig:001 width=70%}

Продемонстрирую работу написанного скрипта: (рис. [-@fig:002]).

![Демонстрируем работу](/home/mavinogradova/skreens/skreens 12/скрины 12/2.png){#fig:002 width=70%}

2. Написать пример командного файла, обрабатывающего любое произвольное число аргументов командной строки, в том числе превышающее десять. Например, скрипт может последовательно распечатывать значения всех переданных аргументов. (рис. [-@fig:003]).

![Пишем пример командного файла](/home/mavinogradova/skreens/skreens 12/скрины 12/3.png){#fig:003 width=70%}

3. Написать командный файл — аналог команды ls (без использования самой этой команды и команды dir). Требуется, чтобы он выдавал информацию о нужном каталоге и выводил информацию о возможностях доступа к файлам этого каталога.(рис. [-@fig:005]).
