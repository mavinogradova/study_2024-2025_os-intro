## Задание для самостоятельного выполнения

Задана топология сети (рис. 4.2). Предполагается, что маршрутизатор разбивает сеть на две подсети с адресами IPv4 и IPv6:
– подсеть 1: 10.10.1.96/27; 2001:DB8:1:1::/64;
– подсеть 2: 10.10.1.16/28; 2001:DB8:1:4::/64.

Собираем топологию для второй части работы в новом проекте, соединяя два компьютера, два коммутатора и маршрутизатор VyOS (рис. [-@fig:019]).

![Собранная топология для второй части работы](/home/mavinogradova/skreens/SetyLb4/19.png){#fig:019 width=70%}

**1. Характеристика подсетей и расчет адресов**

Для того чтобы понять, какие адреса входят в подсети, произведем расчет масок и диапазонов.

**Подсеть 1: `10.10.1.96/27`**
*   **Маска:** Префикс `/27` означает, что первые 27 бит отведены под адрес сети. В десятичном формате это `255.255.255.224` (так как последний октет `11100000` в двоичной системе равен `128 + 64 + 32 = 224`).
*   **Размер подсети (шаг):** Количество адресов в подсети равно \(2^{32-27} = 2^5 = 32\). Шаг сети равен 32.
*   **Адрес сети:** `10.10.1.96` (так как 96 делится на 32 без остатка).
*   **Широковещательный (broadcast) адрес:** Это последний адрес в подсети. Следующая сеть начинается с `10.10.1.128` (96 + 32), значит, broadcast текущей — это `10.10.1.127`.
*   **Доступные адреса для устройств (hosts):** Это все адреса между сетью и broadcast. То есть от `10.10.1.97` до `10.10.1.126`. Всего \(32 - 2 = 30\) адресов.

**Подсеть 2: `10.10.1.16/28`**
*   **Маска:** Префикс `/28` означает `255.255.255.240` (последний октет `11110000` в двоичной системе равен `128 + 64 + 32 + 16 = 240`).
*   **Размер подсети (шаг):** Количество адресов равно \(2^{32-28} = 2^4 = 16\). Шаг сети равен 16.
*   **Адрес сети:** `10.10.1.16` (делится на 16 без остатка).
*   **Широковещательный (broadcast) адрес:** Следующая сеть начинается с `10.10.1.32` (16 + 16), значит, broadcast текущей — это `10.10.1.31`.
*   **Доступные адреса для устройств (hosts):** От `10.10.1.17` до `10.10.1.30`. Всего \(16 - 2 = 14\) адресов.

**Для IPv6:**
В IPv6 под адрес устройства отводится младшие 64 бита (так как префикс `/64`). Адреса сетей заданы (`2001:DB8:1:1::/64` и `2001:DB8:1:4::/64`), а для устройств доступны любые адреса от `::1` до `::ffff:ffff:ffff:fffe`.

**2. Вариант таблицы адресации**

По условию задания для интерфейсов маршрутизатора необходимо выбрать **наименьший адрес в подсети**. Наименьший доступный адрес для устройств (host) — это адрес сети + 1. 
*   Для первой подсети: `10.10.1.96 + 1 = 10.10.1.97`. Этот адрес назначаем на интерфейс `eth0` маршрутизатора VyOS (обращенный к PC1).
*   Для второй подсети: `10.10.1.16 + 1 = 10.10.1.17`. Этот адрес назначаем на интерфейс `eth1` маршрутизатора VyOS (обращенный к PC2).

Оконечным устройствам (PC1 и PC2) назначаем следующие свободные адреса в этих подсетях (например, `.98` и `.18`), а в качестве шлюза по умолчанию указываем адреса маршрутизатора.

| Устройство | Интерфейс | IPv4-адрес | Шлюз по умолчанию (IPv4) | IPv6-адрес | Шлюз по умолчанию (IPv6) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| msk-mavinogradova-gw-01 | eth0 | 10.10.1.97/27 | — | 2001:DB8:1:1::1/64 | — |
| msk-mavinogradova-gw-01 | eth1 | 10.10.1.17/28 | — | 2001:DB8:1:4::1/64 | — |
| PC1-mavinogradova | NIC | 10.10.1.98/27 | 10.10.1.97 | 2001:DB8:1:1::a/64 | 2001:DB8:1:1::1 |
| PC2-mavinogradova | NIC | 10.10.1.18/28 | 10.10.1.17 | 2001:DB8:1:4::a/64 | 2001:DB8:1:4::1 |
